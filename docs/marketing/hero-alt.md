## Supporting Copy

- **Prototype:** Each version is a folder with `index.html` and local assets. Open it directly, with no build step or network dependencies.
- **Versioning:** Copy the most recently edited version or start from an earlier one before exploring another direction.
- **Collaboration:** Exchange work orders and deliveries through a separate private GitHub repository. Designers work without running Git or accessing product code.
- **Setup:** Either collaborator can start with a prompt in Claude Code or Codex, then invite the other person with a join prompt.
