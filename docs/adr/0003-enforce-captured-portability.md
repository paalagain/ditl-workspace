# Enforce portability on the captured delivery

Both send commands enforce the self-contained prototype format when the designer selects a numbered version. Developers can open these versions without a build step or runtime network dependencies. The check uses the exact captured bytes and applies even when the designer acknowledges unfinished tasks. Final delivery also reassesses the agreed tasks and retains any acknowledgment. Designer completion remains separate from developer acceptance.

`send` also accepts explicitly selected files and folders as a progress delivery. This lets the designer share a first pass of screenshots, notes or other files as supplied. These deliveries use the same capture, archive and reception checks and carry a distinct manifest format.
